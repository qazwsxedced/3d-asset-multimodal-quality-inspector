# Data directory

The project data is generated by `blender/generate_scene_dataset.py` and `scripts/generate_synthetic_dataset.py`.

The public repository keeps the data protocol, a manifest example, and the generation scripts, but does not commit batch-rendered images. Images, caches, and large generated datasets are local experiment artifacts excluded by `.gitignore`.

The real experiment uses:

```text
data/blender_research_v3/manifest.jsonl
```

This dataset contains 120 samples with a scene-level train/val/test split of 84/12/24.

The public manifest preserves the complete protocol and relative image paths, but the batch-rendered PNG files are not included in Git. After cloning the repository, regenerate the images before running validation; otherwise the validator will report missing images, which is expected.

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" `
  -b `
  -P blender/generate_scene_dataset.py `
  -- `
  --out data/blender_research_v3 `
  --n 120 `
  --views 4 `
  --seed 23
```

Then run:

```powershell
& ".\.venv\Scripts\python.exe" scripts/validate_dataset.py `
  --manifest data/blender_research_v3/manifest.jsonl
```
