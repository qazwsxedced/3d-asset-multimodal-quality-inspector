# 多图与结构化元数据融合的视觉语言模型推理研究

## 摘要

视觉语言模型（Vision-Language Model, VLM）能够同时处理图像与文本，但其对三维资产质量问题的结构化诊断能力仍缺乏系统评估。本文构建了一个基于 Blender 的可控合成研究框架，研究多视角图像、UV/法线诊断图和低层结构化几何元数据分别及联合使用时，对视觉语言模型三维资产质量诊断能力的影响。我们设计了 B0-B4 五种输入条件：单视图渲染、多视角渲染、多视角加 UV/法线诊断图、多视角加结构化元数据，以及在 B3 条件上进行 LoRA/QLoRA 监督微调。

第二阶段数据集包含 600 个独立 Blender 场景、五类基础几何资产、四个相机视角和六类可控缺陷，训练集、验证集和测试集分别为 420、60 和 120 条。我们同时实现了一个不读取诊断标签的确定性元数据规则基线，用于检验低层几何统计本身的可判别性。实验使用 Qwen2.5-VL-3B-Instruct，并在 8 GB 显存环境下完成 4-bit LoRA 训练。

在 120 条测试样本上，零样本 B0、B1、B2 和 B3 的缺陷 Macro-F1 均为 0；B4 在三个随机种子上的平均缺陷 Macro-F1 达到 82.55% +/- 0.72%，质量准确率为 85.83% +/- 4.33%，严重程度准确率为 75.56% +/- 6.25%。未见场景上的平均缺陷 Macro-F1 为 84.19% +/- 1.48%，而未见问题类型上的平均缺陷 Macro-F1 为 52.19% +/- 12.55%。误差分析显示，模型能够较稳定地识别退化面、孔洞、非流形、翻转法线和 UV 重叠，但对拉伸三角形的召回率为 0。结果表明，任务特定的多模态 LoRA 适配能够显著提升结构化三维质量诊断能力，但当前实验不支持通用 VLM 推理或跨医学、自动驾驶等领域泛化结论。

**关键词：** 视觉语言模型；多视角图像；结构化元数据；三维资产质量诊断；LoRA；QLoRA；Blender

## 1 引言

三维资产质量检查通常需要同时观察模型外观、拓扑结构、UV 展开和法线方向。传统工具可以通过确定性几何算法检测非流形边、边界边、退化面和 UV 重叠，但这类工具通常不能直接理解自然语言问题，也难以将多种视觉证据组织成统一的质量诊断结果。近年来，视觉语言模型在图像问答和结构化生成任务上取得进展，为三维资产质检提供了新的研究方向。

然而，三维资产诊断与普通图像问答不同。缺陷可能只在特定视角中可见，也可能无法从普通渲染图直接观察；几何统计能够提供精确的低层信号，但同时存在提示词泄漏和模型机械读取字段的风险。因此，需要一个具有明确输入协议、控制变量和场景级数据划分的实验框架。

本文围绕以下问题展开研究：

> 多视角图像、UV/法线诊断图和低层结构化几何元数据，分别以及联合使用时，对 VLM 的三维资产质量诊断和结构化输出能力有多大影响？

本文的主要贡献如下：

1. 构建了一个可重复的 Blender 多视角三维资产诊断数据生成管线，并实现六类可控缺陷注入。
2. 设计了 B0-B4 消融协议，使不同输入模态和 LoRA 适配的影响能够在相同测试样本上比较。
3. 实现了 JSON 有效率、字段准确率、多标签缺陷 Macro-F1、延迟和泛化分组等评测指标。
4. 使用确定性规则基线和三随机种子 B4 实验，区分几何信号可判别性、VLM 零样本能力和微调稳定性。

## 2 相关方法与问题定义

### 2.1 诊断任务

每个样本对应一个独立三维资产，模型需要输出一个 JSON 对象：

```json
{
  "quality": "pass|fail",
  "defect_types": ["defect name"],
  "severity": "none|low|medium|high",
  "repair_plan": ["short repair action"]
}
```

缺陷类型包括 `degenerate_faces`、`flipped_normals`、`hole`、`non_manifold`、`stretched_triangles` 和 `uv_overlap`。元数据只提供低层几何统计，例如面数、边界边数量、非流形边数量、退化面数量、翻转法线数量、三角形面积统计、三角形长宽比统计和 UV 重叠比例，不直接提供 `has_defect` 或 `is_manifold` 等诊断结论。

### 2.2 B0-B4 输入协议

| 条件 | 输入 |
|---|---|
| B0 | 一张普通渲染图 |
| B1 | 四张不同视角的普通渲染图 |
| B2 | 四张普通渲染图 + UV/法线诊断图 |
| B3 | 四张普通渲染图 + 低层结构化几何元数据 |
| B4 | B3 输入 + LoRA/QLoRA 监督微调 |

B4 只在 B3 协议上训练，避免将训练收益和输入模态变化混为一谈。所有 B0-B4 结果均使用固定测试集 ID。

## 3 数据集与数据生成

### 3.1 场景构造

第二阶段数据集由 Blender 自动生成，包含 `ico_sphere`、`cube`、`cylinder`、`cone` 和 `torus` 五类资产。每个样本使用一个独立场景，资产的几何类别、尺度、旋转和材质颜色在四个相机视角之间保持一致。相机方位角为 0、90、180 和 270 度，仰角为 20 度。

数据集规模为 600 条，其中 420 条用于训练，60 条用于验证，120 条用于测试。数据按场景 ID 划分，避免同一场景的不同视角跨越训练集和测试集。测试集包含 12 个无缺陷样本和 108 个缺陷样本。

### 3.2 缺陷注入

数据生成器在 Blender 网格上注入六类缺陷，并同步提取几何统计和诊断标签：

- 非流形结构：制造共享边拓扑异常。
- UV 重叠：复制有效 UV 三角形的 UV 坐标。
- 翻转法线：翻转部分面的顶点顺序。
- 拉伸三角形：改变局部几何比例，使三角形长宽比升高。
- 退化面：生成零面积或近零面积面。
- 破洞：删除局部面，形成边界边。

生成后，`validate_dataset.py` 检查 JSONL 完整性、图片路径、场景级切分和黑名单字段；正式 600 条数据的验证错误数为 0。

## 4 实验设置

### 4.1 模型与训练

基础模型为 Qwen2.5-VL-3B-Instruct。B0-B3 使用确定性解码进行零样本推理。B4 使用 LoRA/QLoRA 进行一轮监督微调，LoRA rank 为 16，alpha 为 32，dropout 为 0.05，学习率为 `2e-4`，梯度累积步数为 8，4-bit NF4 量化，训练图像像素范围为 25,088-50,176。训练在 RTX 4060 Laptop GPU、8 GB 显存环境下完成。

为评估随机性，B4 使用 seed 42、123 和 3407 重复训练。主表中的 B4 数字为 seed 42，稳定性结果报告三个 seed 的均值和样本标准差。

### 4.2 评测指标

- **Quality accuracy：** `quality` 字段准确率。
- **Severity accuracy：** `severity` 字段准确率。
- **Defect exact accuracy：** 预测缺陷集合与 gold 集合完全一致的比例。
- **Defect Macro-F1：** 将缺陷类型视为多标签分类，计算各类 F1 的宏平均。
- **JSON valid rate：** 输出可被解析为 JSON 对象的比例。
- **Schema valid rate：** 输出满足字段、枚举值和列表类型约束的比例。
- **Latency：** 单样本生成延迟，报告平均值、P50 和 P95。

## 5 实验结果

### 5.1 B0-B4 对照实验

| 条件 | Quality accuracy | Severity accuracy | Defect Macro-F1 | JSON 有效率 | Schema 有效率 | 平均延迟 |
|---|---:|---:|---:|---:|---:|---:|
| B0 | 69.17% | 48.33% | 0.00% | 100.00% | 0.00% | 4.62 s |
| B1 | 44.17% | 51.67% | 0.00% | 100.00% | 0.00% | 4.89 s |
| B2 | 20.00% | 53.33% | 0.00% | 100.00% | 0.00% | 4.93 s |
| B3 | 32.50% | 43.33% | 0.00% | 100.00% | 0.00% | 4.16 s |
| B4 | 88.33% | 81.67% | 82.98% | 99.17% | 99.17% | 4.71 s |

零样本条件下，多视角和诊断图并未自动带来性能提升。B1 相比 B0 的质量准确率下降，B2 进一步下降，说明基础模型可能无法正确组织多图输入或理解当前 UV/法线图的视觉编码。B3 也没有直接利用结构化元数据完成缺陷分类。相比之下，B4 在保持相同 B3 输入协议的情况下显著提升了所有主要诊断指标。

### 5.2 确定性规则基线

规则基线只使用训练集拟合的低层元数据阈值，不读取诊断标签字段。其测试结果为：质量准确率 95.00%，严重程度准确率 93.33%，缺陷 exact accuracy 92.50%，缺陷 Macro-F1 95.71%，修复计划 exact accuracy 86.67%。

该结果说明，几何统计本身包含足够的缺陷判别信号；零样本 VLM 的失败主要反映了从结构化数字到诊断 schema 的推理和输出适配不足，而不是数据标签完全不可用。

### 5.3 三随机种子稳定性

| 指标 | 三 seed 均值 +/- 标准差 |
|---|---:|
| Quality accuracy | 85.83% +/- 4.33% |
| Severity accuracy | 75.56% +/- 6.25% |
| Defect Macro-F1 | 82.55% +/- 0.72% |
| JSON/Schema 有效率 | 94.72% +/- 7.70% |

未见场景上的质量准确率为 92.59% +/- 0.64%，缺陷 Macro-F1 为 84.19% +/- 1.48%。未见问题类型上的质量准确率为 65.56% +/- 19.25%，缺陷 Macro-F1 为 52.19% +/- 12.55%。这说明模型对新场景的泛化较稳定，但对问题表达方式和任务类型变化更敏感。

### 5.4 缺陷级误差分析

seed 42 的 B4 缺陷级结果如下：

| 缺陷 | Precision | Recall | F1 |
|---|---:|---:|---:|
| degenerate_faces | 1.000 | 1.000 | 1.000 |
| flipped_normals | 1.000 | 0.958 | 0.979 |
| hole | 1.000 | 1.000 | 1.000 |
| non_manifold | 1.000 | 1.000 | 1.000 |
| stretched_triangles | 0.000 | 0.000 | 0.000 |
| uv_overlap | 1.000 | 1.000 | 1.000 |

拉伸三角形是主要失败类型。虽然数据中提供了三角形长宽比统计，但当前图像、提示词和训练样本没有形成足够稳定的语义映射。该结果给出了明确的后续实验方向：增加拉伸程度分层、补充边界案例、在 prompt 中显式解释 aspect ratio 与拉伸缺陷的关系，并比较仅使用 metadata 与 B4 的差异。

## 6 讨论

第一，B0-B3 的结果说明“增加输入模态”并不等价于“模型自动获得有效推理能力”。多视角图像提高了信息量，却也增加了图像组织和证据对应的难度；UV/法线诊断图如果没有稳定的视觉编码或训练示例，可能成为噪声；结构化 metadata 虽然精确，却要求模型学习数字阈值与缺陷语义之间的映射。

第二，B4 的提升说明任务特定的 LoRA 适配能够将这些输入协议转化为结构化诊断能力。B4 与规则基线之间仍存在差距，但三 seed 的缺陷 Macro-F1 标准差较小，表明主要缺陷类别的学习相对稳定。

第三，未见问题类型的性能波动显著大于未见场景，说明当前研究不仅是视觉识别问题，也包含任务指令理解和结构化输出泛化问题。因此，未来应将问题模板划分、输出 schema 设计和校准评估作为独立研究变量。

## 7 局限性

1. 数据由 Blender 合成，不能直接代表真实生产环境中的复杂网格、材质、遮挡和扫描噪声。
2. 当前正式数据规模为 600 条，虽然足以完成受控消融，但仍不足以支持广泛领域泛化结论。
3. B4 只训练一个 epoch，且使用 8 GB 显存下的低像素设置，训练效率与视觉细节之间存在折中。
4. 拉伸三角形缺陷尚未被模型可靠识别，说明当前数据和 prompt 设计仍需针对性优化。
5. 三 seed 只评估了同一测试集，尚未进行真实 3D 资产或外部 benchmark 验证。

## 8 结论

本文构建了一个面向三维资产质量诊断的多图与结构化元数据融合 VLM 研究框架。通过 B0-B4 受控实验、确定性规则基线和三随机种子 LoRA 训练，我们发现：零样本 Qwen2.5-VL-3B 对当前多模态诊断协议的缺陷识别能力有限，而任务特定的 B4 LoRA 适配能够将缺陷 Macro-F1 提升到三 seed 平均 82.55%。模型对未见场景的泛化较稳定，但对未见问题类型仍存在明显波动。该项目验证了数据构造、模态消融、LoRA 适配、结构化评测和误差分析组成的一条完整研究路线，同时明确了拉伸三角形识别、真实资产验证和更系统的泛化实验作为后续工作。
